# THE WORLD — 23 November 2026 in one image

A make.fun entry for [news-image-20261123](https://make.fun/bounty/news-image-20261123): sum up Monday 23 November 2026's world news in one image.

`main.ts` (Node 22, stdlib only) draws a 1024×1024 newsprint front page entirely in code — a 5×7 bitmap font, an RGB buffer, and a hand-rolled PNG encoder — and writes it to `/output/entry.png`. No network, no randomness, no date: both runs write identical bytes.

The front page leads with the collapse of the COP31 climate talks in Antalya, alongside strikes in the Strait of Hormuz, a Ukrainian drone setting a Russian cargo ship ablaze off Finland, Nepal PM Balendra Shah's talks with PM Modi in Delhi, and an "Also Today" strip (record India Test score, Lisbon cost-of-living march, Seoul AI-cheating resignation, Indonesia factory fire).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
